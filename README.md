# Project Title: Guessing Game! 

## Project Description: 
Our project is a simple Python game designed to serve as a demonstration of fundamental Python programming construction. It provides an engaging environment to review and apply different core concepts such as user input, output, arithmetic calculations, and logical / relational operations. 

## Features: 
- Manual input of the players' username 
- Item Selection: Allows the user to choose a number / item from a predefined list.
- Manages invalid inputs from the user
- Provides feedback from the outcome based on the relational operations used ( == ).
- Price Guessing: Prompts the user to guess the hidden price of the chosen number from 1 to 5.

## How to Run the Program: 
1.) Make sure a Compiler or Python is installed.
2.) Download the "guessing game.py" as file.
3.) Open your terminal / command prompt and locate where the file is saved.
4.) Run the script using Python or a Compiler by pressing "Run", or by pressing key F5.
5.) Follow the prompts in the screen for guidance.
